# Global Hail–Lightning Coupling
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22766712.svg)](https://doi.org/10.5281/zenodo.22766712)

Code supporting the study:

**Global hail–lightning coupling reorganizes in a warmer climate**

This repository contains the code used to process CMIP6 data,
train and evaluate XGBoost models, perform future projections and counterfactual
attribution analyses, and generate the figures used in the manuscript.

## Repository structure

The code and documentation are currently being organized.

## Data availability

The LIS/OTD 0.5° High Resolution Full Climatology (HRFC v2.3.2015) is publicly available from 
the NASA Global Hydrometeorology Resource Center: https://doi.org/10.5067/LIS/LIS-OTD/DATA311. 

The GPM precipitation feature database is publicly available from the precipitation feature database 
maintained by Liu and collaborators: https://atmos.tamucc.edu/trmm/data/gpm/level_2/. 

CMIP6 outputs from CanESM5, MIROC6, and BCC-CSM2-MR are available from https://metagrid.esgf-west.org/search/cmip6/. 

The dataset generated and analysed during the current study
is available in the Zenodo repository at https://doi.org/10.5281/zenodo.22754623.
